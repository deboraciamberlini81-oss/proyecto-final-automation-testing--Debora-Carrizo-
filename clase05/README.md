# Clase05 - Calculadora

## Descripción

Proyecto de una calculadora estática realizada con HTML y CSS.

La actividad tiene como objetivo practicar:

- Estructura HTML.
- CSS externo.
- Identificadores estables.
- Clases semánticas.
- Inspección de elementos mediante DevTools.
- Creación de selectores para futuras pruebas UI.
