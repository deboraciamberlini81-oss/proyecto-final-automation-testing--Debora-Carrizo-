# Pre-Entrega Automation Testing - Debora Carrizo

## Propósito

Este proyecto tiene como objetivo automatizar pruebas funcionales sobre la aplicación web SauceDemo, utilizando Selenium WebDriver y Pytest.

Las pruebas permiten verificar el inicio de sesión, la navegación del catálogo, la visualización de productos y la interacción con el carrito de compras.

## Tecnologías utilizadas

- Python 3.12
- Selenium WebDriver
- Pytest
- pytest-html
- Visual Studio Code
- Git
- GitHub
